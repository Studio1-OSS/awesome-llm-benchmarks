# 2D Breakout

Build a complete, polished breakout game as a standalone browser experience.

## Status

**Ready for runs.** No model outputs have been added yet.

## Prompt

The shared prompt is not finalized. Before the first run, add the verbatim prompt here and use it unchanged for every model in this test.

The prompt should specify the required game loop, controls, visual direction, score and life systems, restart behavior, responsiveness, and the expected delivery format.

## Heuristic

| Criterion | Weight | What good looks like |
| --- | ---: | --- |
| Playability | 30% | Paddle, ball, brick, life, and restart mechanics are predictable and complete. |
| Game feel | 25% | Input, bounce physics, pacing, and feedback make another round appealing. |
| Visual craft | 20% | The visual system is coherent, readable, and supports play. |
| Feedback | 15% | Score, lives, effects, sound, and state changes are clear and useful. |
| Technical quality | 10% | The HTML opens reliably and works without hidden dependencies. |

## Run protocol

1. Use the shared prompt with no unrecorded follow-up changes.
2. Record the exact model name, provider, interface, date, settings, token usage, and cost.
3. Save the complete runnable artifact in the model folder.
4. Play the result before writing observations.
5. Record limitations separately from the verdict.
