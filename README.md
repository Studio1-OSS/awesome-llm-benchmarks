An interactive, web-based UI for exploring the [Awesome LLM Benchmarks](https://github.com/Studio1-OSS/awesome-llm-benchmarks) project. This interface allows you to select various coding and design benchmarks (such as 3D games, endless runners, and design portfolios) and perform side-by-side evaluations of the HTML outputs generated by state-of-the-art Large Language Models.

## 🚀 Features

- **Side-by-Side Comparisons:** Evaluate up to 3 LLM outputs simultaneously in sandboxed iframes.
- **Detailed Benchmark Reports:** View parsed Markdown `README.md` files for every benchmark, complete with full prompt details, cost breakdowns, and verdicts.
- **Intelligence vs. Cost Analysis:** Built-in charts (using Recharts) to analyze the performance of various LLMs on the Artificial Analysis Intelligence Index vs. Cost per Task.
- **Dynamic Trending Models:** Automatically tracks and compares models such as GPT-4, Claude 3.5 Sonnet, DeepSeek, and more.
- **Contribute CTA:** Missing models for a benchmark? A dedicated empty state guides users to contribute their own runs via GitHub.

## 🛠️ Technology Stack

- **Framework:** React 18
- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** Custom Vanilla CSS with a polished, modern, glassmorphism aesthetic.
- **Charts:** [Recharts](https://recharts.org/) for data visualization.
- **Markdown:** `react-markdown` and `remark-gfm` for robust GitHub-flavored Markdown rendering.

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Studio1-OSS/awesome-llm-benchmarks.git
   cd awesome-llm-benchmarks
   git checkout UI
   ```
   *(Note: The UI codebase resides in the `UI` branch)*

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `src/App.tsx`: Main application entry point, containing the sidebar, benchmark selection dropdown, evaluation cards, and the interactive Recharts dashboard.
- `public/awesome-llm-benchmarks/`: A synchronized embedded repository containing the raw markdown benchmarking data and raw HTML generation outputs.
- `src/index.css`: Custom utility classes and core styling tokens that define the application's premium aesthetic.

## 🤝 Contributing

We welcome contributions! If you've run a new model against one of our benchmarks, you can submit the raw output to expand the arena.

1. Fork the main repository.
2. Follow the prompt for a specific game (e.g., `endless-runner`).
3. Add the output `index.html` and update the `README.md` table for that game.
4. Submit a Pull Request!
