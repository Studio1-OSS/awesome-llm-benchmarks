# Endless Runner

Create a browser-based endless runner with a memorable world, tight controls, and a compelling repeat-play loop.

## Status

## Prompt

The shared prompt is not finalized. Add it verbatim before the first run and keep it identical across models.

The prompt should define movement, obstacles, scoring, difficulty progression, restart behavior, visual direction, input support, sound, responsiveness, and expected delivery format.

## Heuristic

| Criterion | Weight | What good looks like |
| --- | ---: | --- |
| Game feel | 30% | Movement and jumping feel immediate, controlled, and satisfying. |
| Core loop | 25% | Obstacles, score, difficulty, loss, and restart work as one coherent system. |
| Visual direction | 20% | The world has a clear identity that supports the action. |
| Feedback | 15% | Animation, sound, UI, and collision responses communicate state well. |
| Technical quality | 10% | The browser artifact is stable and self-contained. |
