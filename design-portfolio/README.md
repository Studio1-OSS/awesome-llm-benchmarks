# Design Portfolio

Create a photography portfolio that feels editorial, distinctive, and effortless to navigate.

## Status

**Ready for runs.** No model outputs have been added yet.

## Prompt

**Prompt used for this test:**

> Create one complete HTML file for a refined photography portfolio for an imaginary editorial photographer. Design a calm, image-first home page with a memorable identity, project grid, short artist statement, selected client list, and simple contact call to action. Use a restrained typographic system, generous spacing, subtle hover states, and a responsive layout that looks intentional on desktop and mobile. Use remote placeholder photography from Unsplash Source URLs so the page is immediately visual. Keep navigation simple and make the design feel authored rather than template-like. Return only the complete working HTML with all CSS and JavaScript included.

## Heuristic

| Criterion | Weight | What good looks like |
| --- | ---: | --- |
| Art direction | 30% | Type, color, image treatment, and layout form a confident, specific point of view. |
| Editorial hierarchy | 25% | Work, context, and calls to action are easy to scan and naturally sequenced. |
| Interaction and motion | 20% | Movement and navigation feel intentional and never compete with the work. |
| Responsive craft | 15% | The design remains legible and persuasive on small and large screens. |
| Technical quality | 10% | The artifact is stable, accessible, and self-contained. |
